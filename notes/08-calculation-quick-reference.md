# 计算题速查与校验

本页只保留网络工程师高收益计算。任何公式先写变量含义和单位，再代入。

## 单位

```text
1 B = 8 bit
1 ms = 10^-3 s
1 us = 10^-6 s
1 ns = 10^-9 s
通信速率常用：1 kbit/s = 10^3 bit/s，1 Mbit/s = 10^6 bit/s
```

题干给存储容量时注意 `KB/MB` 是否按 `2^10/2^20`；不要把存储换算规则无条件套到链路速率。

## 时延、吞吐与利用率

```text
发送时延 = 帧长(bit) / 速率(bit/s)
传播时延 = 距离(m) / 传播速度(m/s)
吞吐率 = 有效数据量(bit) / 总时间(s)
利用率 = 吞吐率 / 标称速率
a = 传播时延 / 发送一帧时延
```

理想无差错停等协议、忽略 ACK 发送时间和处理时间时：

```text
U = 1 / (1 + 2a)
```

若题目给 ACK 长度、处理时间、差错率或窗口，必须改用完整条件，不能硬套简式。

校验：利用率应在 0 到 1 之间；结果大于 1 通常是单位或模型错。

## 信道容量

```text
Nyquist：Rmax = 2B log2(M)
Shannon：C = B log2(1 + S/N)
dB = 10 log10(S/N)
```

例：`B=3 kHz`、`S/N=30 dB`，先得线性比 `1000`，再计算 `C=3000×log2(1001)`，约为 `29.9 kbit/s`。

## PCM/TDM

```text
采样率 fs >= 2fmax
单路 PCM 速率 = fs × 每样本位数
多路净荷速率 = 单路速率 × 通道数
```

若每帧有同步位或信令开销：总速率 = 每帧总位数 × 帧率。

## 子网与 VLSM

### 固定前缀

1. 前缀 `/p`，主机位 `h=32-p`。
2. 地址块大小：在变化的八位组中为 `256-掩码值`。
3. 网络地址向下取块边界，广播地址为下个块起点减 1。
4. 常规可用主机范围是网络地址加 1 到广播地址减 1。

例：`192.168.10.77/27`，块大小 32，77 位于 64—95：

```text
网络地址 192.168.10.64
广播地址 192.168.10.95
可用主机 192.168.10.65—192.168.10.94
可用数量 2^5 - 2 = 30
```

### VLSM

按主机需求从大到小：为每组找到满足 `2^h - 2 >= hosts` 的最小 `h`，得到前缀 `32-h`，再从地址边界顺序分配。

校验：每个网络起点必须是其块大小的整数边界，且子网不得重叠。

## 路由聚合

1. 把候选网络地址写为二进制。
2. 从最高位开始找连续公共前缀。
3. 公共位数就是汇总前缀；其后全置 0 得汇总网络地址。

校验：汇总必须覆盖全部目标网段。若同时覆盖额外地址，要判断题目是否允许；实际设计还要防止汇总黑洞。

## IPv4 分片

```text
每个非末片最大数据量 = floor((MTU - 首部长度) / 8) × 8
片偏移 = 本片原始数据起始位置 / 8
片总长度 = 首部长度 + 本片数据长度
```

除最后一片外 MF=1，最后一片 MF=0；同一原始数据报 Identification 相同。

## CRC

若生成多项式最高次数为 `r`：数据后补 `r` 个 0，做模 2 除法，取 `r` 位余数。接收端用完整码字再除，余数应为 0。

校验：模 2 运算只有 XOR，无进位、借位。

## 海明码

```text
2^r >= m + r + 1
```

校验位放 `1、2、4、8...` 位。题目若只问最少校验位，满足不等式即结束；若问纠错，需按奇/偶校验约定计算综合症。

## CSMA/CD 最短帧

发送方必须在仍发送时检测到最远端碰撞：

```text
最短帧长(bit) >= 2 × 单向传播时延(s) × 数据速率(bit/s)
```

若计入中继器或物理层延迟，按题干加入往返路径。结果换成字节时向上取整。

## 系统可靠性

```text
串联：R = ΠRi
并联：R = 1 - Π(1-Ri)
```

概率必须在 0 到 1 之间；百分数先除以 100。

## 考场四步

1. 圈单位和关键词；
2. 写公式/边界；
3. 代入并保留合理有效数字；
4. 用数量范围、反向代入或二进制边界独立校验。
