# 局域网、VLAN、STP 与 WLAN

## Ethernet 必记

- 典型 Ethernet II 帧：目的 MAC 6 B、源 MAC 6 B、类型 2 B、数据 46—1500 B、FCS 4 B。
- 前导码和帧开始定界符用于同步，通常不计入 MAC 帧长度；是否计入线路传输量按题干口径。
- 交换机每个端口划分冲突域；路由器或 VLAN 边界划分广播域。
- 半双工共享以太网使用 CSMA/CD；全双工交换网络不需要碰撞检测。
- 二层交换机依据源 MAC 学习、依据目的 MAC 转发。未知单播、广播及相应 VLAN 内的部分组播会被泛洪。

常见标准：

| 标准 | 高频关联 |
|---|---|
| IEEE 802.3 | Ethernet |
| IEEE 802.1Q | VLAN 标签 |
| IEEE 802.1D | 传统桥接/STP 基础 |
| IEEE 802.1w | RSTP |
| IEEE 802.1s | MSTP |
| IEEE 802.1AX | 链路聚合；旧资料常写 802.3ad |
| IEEE 802.11 | WLAN 系列 |

## VLAN 与 Trunk

- Access 端口通常只承载一个 VLAN，面向终端。
- Trunk 端口可承载多个 VLAN，常用于交换机互联或交换机到支持 VLAN 的上级设备。
- 802.1Q 标签为 4 B，其中 VLAN ID 有 12 位；可用普通 VLAN ID 通常为 1—4094，0 和 4095 保留。
- Native/PVID 的无标签处理依赖厂商与端口配置。做题时先看题干的 PVID、允许 VLAN 列表和收发方向。

排查 VLAN 不通的最短路径：

1. 接入口 VLAN 是否正确；
2. VLAN 是否已创建且端口状态正常；
3. Trunk 是否允许该 VLAN；
4. 两端 PVID/标签预期是否一致；
5. 三层网关、掩码和回程路由是否正确。

## STP/RSTP/MSTP

### STP 选举顺序

1. Bridge ID 最小者成为根桥。比较时先看优先级，再看 MAC。
2. 非根交换机选择到根路径开销最小的根端口；平局再按上游 BID、端口 ID 等规则比较。
3. 每个网段选择到根路径最优的指定端口。
4. 剩余冗余端口进入阻塞/丢弃角色，消除二层环路。

易错点：

- “带宽最大”不是根桥直接选举条件；路径开销才与链路速率相关。
- STP 端口角色与状态不是同一个概念。
- RSTP 通过新的角色和握手机制加快收敛，但仍以无环拓扑为目标。
- MSTP 可把多个 VLAN 映射到不同实例，以减少实例数量并实现负载分担。

## 链路聚合

- 目标：扩展总带宽、提供成员链路冗余，并让逻辑链路参与生成树和路由。
- LACP 用于动态协商聚合成员。两端的速率、双工、VLAN/Trunk 等关键属性必须兼容。
- 单个流通常按哈希固定到一个成员链路，不能简单认为单会话速度等于所有成员带宽之和。

## WLAN

- AP 提供无线接入；BSS 是一组按同一协调功能工作的站点，基础设施模式下通常由 AP 协调。
- 802.11 使用 CSMA/CA，原因是无线终端难以像有线共享介质那样边发边可靠检测碰撞。
- RTS/CTS 主要缓解隐藏节点问题，会增加控制开销，不是任何场景都应开启。
- 2.4 GHz 覆盖相对好但干扰较多；5 GHz 通常可用信道更多、速率高但穿透与覆盖条件不同；具体能力看标准、带宽和法规域。
- 安全优先选择 WPA2-AES 或 WPA3 等现代方案；WEP 与早期 TKIP 不应作为实际部署建议。

## 考场陷阱

- 568A 与 568B 是双绞线端接线序；两端同标准是直通线，一端 A 一端 B 是交叉线。现代设备可能支持自动翻转，但考试常按传统用途判断。
- 堆叠把多台设备作为更统一的逻辑系统管理；级联只是链路连接，不能把两者混同。
- PoE 是在以太网布线上供电，功率等级和供电协商需看具体标准，不能只背“48 V”。
