# 网络基础与数据通信

## 考场结论

- OSI 七层从下到上：物理、数据链路、网络、传输、会话、表示、应用。设备或协议归层时看它“主要处理的对象”，不要只看名称。
- `bit/s` 是速率，`B` 是字节；`1 B = 8 bit`。通信速率常按十进制换算，存储容量题按题干决定是否使用二进制倍数。
- 传输时延取决于数据量和链路速率；传播时延取决于距离和介质传播速度。提高带宽不能缩短已经确定的传播距离。
- 无噪声信道用 Nyquist，带噪信道用 Shannon。看到带宽 `B`、信噪比 `S/N` 和 `dB` 要先判断公式。
- PCM 顺序是采样、量化、编码；采样频率至少满足 `fs >= 2fmax`，考试通常写为大于等于最高频率的两倍。
- CRC 用模 2 除法，只做异或、不借位；海明码先判校验位个数，再按位序计算校验关系。

## 分层与数据单元

| 层 | 主要任务 | 常见识别词 | 数据单元 |
|---|---|---|---|
| 应用层 | 向应用提供网络服务 | HTTP、DNS、SMTP、SNMP | 报文 |
| 表示层 | 编码、压缩、加密、格式转换 | 字符集、序列化 | 数据 |
| 会话层 | 建立、管理、恢复会话 | 对话控制、同步点 | 数据 |
| 传输层 | 端到端复用、可靠性、流量控制 | TCP、UDP、端口 | 段/用户数据报 |
| 网络层 | 逻辑寻址和路由选择 | IP、路由器、分组 | 分组/数据报 |
| 数据链路层 | 成帧、MAC、差错检测 | Ethernet、VLAN、交换机 | 帧 |
| 物理层 | 透明传输比特 | 电气、光学、接口、编码 | 比特 |

记忆时不要把“加密必在表示层”绝对化。实际协议可在不同层提供加密，考试归层题看题目采用的模型语境。

## 速率与时延

总时延通常拆成：

```text
总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
发送时延 = 数据量(bit) / 发送速率(bit/s)
传播时延 = 距离(m) / 传播速度(m/s)
```

易错点：

- 吞吐量是实际完成的有效数据速率，不必等于链路标称带宽。
- 往返时间 RTT 通常约含两次单向传播及各节点处理/排队时间；题干简化时以给定条件为准。
- 多段链路若采用存储转发，完整帧往往需在每段重新发送；是否计入处理时延看题干。

## Nyquist 与 Shannon

```text
Nyquist：Rmax = 2B log2(M)
Shannon：C = B log2(1 + S/N)
dB = 10 log10(S/N)
```

- `B` 单位为 Hz，结果为 bit/s；`M` 是离散信号状态数。
- 题目给 `30 dB` 时，线性信噪比是 `10^(30/10)=1000`，不能把 30 直接代入 Shannon。
- 两个上限同时存在时，实际理论上限不能超过较小者。

## 编码与调制

- 数字数据用数字信号承载属于编码；数字数据变为模拟载波属于调制。
- Manchester 每个比特中间都有跳变，可自同步但所需带宽较高。
- 差分 Manchester 也保证位中间跳变，数据由位开始处是否跳变表示；具体 0/1 约定以题图为准。
- ASK 改幅度，FSK 改频率，PSK 改相位，QAM 同时利用幅度和相位。

## PCM

若每个样本量化为 `n` 位、采样率为 `fs`：

```text
编码速率 = fs × n
量化级数 = 2^n
```

多路 TDM PCM 还要乘通道数，并按题干加入同步位或帧开销。

## 差错检测

### CRC

1. 生成多项式最高次数为 `r`，在数据后补 `r` 个 0。
2. 用生成多项式对应比特串做模 2 除法。
3. `r` 位余数替换补 0 位置形成发送码字。
4. 接收端用同一生成多项式相除，余数为 0 表示“未检测到错误”，不等于绝对无错。

### 海明码

信息位数为 `m` 时，校验位数 `r` 满足：

```text
2^r >= m + r + 1
```

校验位放在位序 `1、2、4、8...`。综合校验结果可定位一位错误；若题目涉及 SEC-DED，需要额外的总奇偶校验位。

## 易混辨析

- 编译程序一次翻译形成目标程序；解释程序边解释边执行。题目问执行效率与可移植性时要区分运行阶段和开发阶段。
- 绝对路径从根或明确起点定位；相对路径依赖当前工作目录。
- 甘特图擅长显示任务时间条，PERT/网络图擅长依赖与关键路径；两者不是互相完全不能表达。
