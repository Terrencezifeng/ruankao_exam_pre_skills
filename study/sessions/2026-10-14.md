## AR2 路由表填空题

- 学习时长：未记录。
- 题目：根据 AR2 的华为风格路由表判断 DHCP Server 网段、PC1 网段及 AR2 的 GE0/0/0 地址；用户表示最后一空不确定。
- 解析结论：`192.168.1.0/24 Direct` 对应 AR2 直连的 DHCP Server 网段；`192.168.0.0/24 RIP` 对应经 AR1 到达的 PC1 网段；`201.1.1.0/30 Direct` 的下一跳/本地地址列为 `201.1.1.2`，且存在 `201.1.1.2/32 Direct` 本地主机路由，因此 GE0/0/0 地址为 `201.1.1.2`。`201.1.1.1` 是到 `192.168.0.0/24` 的 RIP 下一跳，即 AR1 对端地址。
- 已证明掌握：本次为讲解，尚无独立变式作答证据；网络互联与互联网掌握度维持 2。
- 暴露问题：对动态路由的 `NextHop` 与本机出接口地址的边界不确定，新增 M-20261014-001。
- 后续动作：2026-10-15、10-17、10-21 做短表格变式，10-22 做考前抽查；纳入第 7 周模拟预算，不另加学习时间。

### 补充：拓扑中各设备地址的可确定范围

- 可精确确定：AR2 GE0/0/0 为 `201.1.1.2/30`；AR1 与 AR2 相连接口为 `201.1.1.1/30`；AR2 面向 DHCP Server 的 GE0/0/1 为 `192.168.1.254/24`。
- 只能确定网段：PC1 位于 `192.168.0.0/24`，DHCP Server 位于 `192.168.1.0/24`；题图和 AR2 路由表没有提供二者的具体主机地址。
- 不能精确确定：AR1 面向 PC1 的 LAN 接口地址。它应是 `192.168.0.0/24` 中的某个可用主机地址，并作为 PC1 的网关，但不能仅凭本题断定是 `.1` 或 `.254`。
- 边界提醒：`192.168.1.254` 是 AR2 接口地址，不是 DHCP Server 地址；`201.1.1.1` 是 AR1 对端地址，不是 AR2 地址。
