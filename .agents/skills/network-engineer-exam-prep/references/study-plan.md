# 2026 下半年 8 周冲刺计划

## 排程原则

- 目标考试窗口：2026-10-24 至 2026-10-27，实际时间以准考证为准。
- 基线：有基础但不系统；每周最多 240 分钟，总预算 32 小时。
- 每周至少包含“学习/训练”和“复盘”两类活动。没有题目证据时不跳过诊断。
- 为同时满足“完整 240 分钟模拟”和每周 4 小时上限，完整模拟放在第 7 周；第 8 周只做模考错题回炉和考前速记，不在最后几天新增整套模拟。

每周合计均为 240 分钟。若实际某周少于 240 分钟，优先保留计算、路由交换配置、应用技术和错题复习；压缩低收益的泛读时间。

## 第 1 周诊断要求

- 基础知识：抽取覆盖数据通信、局域网、IP、路由、安全、服务和管理的原创选择题；记录正确、错误以及犹豫但答对。
- 应用技术：至少包含一个 IPv4 地址规划小题和一个配置/故障定位小题。
- 诊断不是追求模拟分数，而是确定未来六周的时间替换依据。

## 动态调整规则

1. 单一知识点首次出错：使用本周复盘时间，不立即改动主计划。
2. 同类题两次错误或应用技术无法下笔：升为高优先级，替换本周一个低收益泛读块。
3. 某科估分低于 50：下一周至少 60% 时间给该科；另一科仍保留错题复习，不能完全停学。
4. 因工作未完成本周任务：只顺延高优先级未完成项；其余重新评估后删除，不把欠账全部堆到下一周。
5. 考前一周不扩展新资料源，不追逐押题；只处理已有错题、命令、公式和时间策略。

## 机考时间默认方案

- 基础知识默认目标 105 分钟：首轮 75 分钟、难题复查 25 分钟、交卷检查 5 分钟。
- 应用技术默认可用 135 分钟；基础知识实际节余时间可转入本段。
- 用户的模拟证据显示某一分配更优时再调整，但基础知识不得少于官方最低 90 分钟或超过 120 分钟。
