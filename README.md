# 软考网络工程师备考助手

这是一个面向 **软考中级网络工程师** 的项目级 Codex Skill，目标是帮助在职考生用有限时间完成学习规划、做题答疑、配置训练、模拟考试和错题复盘。

当前默认备考画像：

- 目标批次：2026 年下半年
- 当前基础：有网络基础，但知识体系不完整
- 时间预算：每周约 4 小时
- 学习方式：自适应答疑，并自动维护进度与错题

## 能做什么

- 根据剩余时间和错题证据制定、调整每周学习计划
- 讲解网络概念、协议、计算公式和易混考点
- 解析基础知识选择题及应用技术题
- 训练 IPv4 子网、路由聚合、编码检错、吞吐量和时延等计算题
- 解析华为或思科配置题，并避免混用厂商命令
- 组织 240 分钟机考模拟并分析两科风险
- 自动记录学习会话、错题原因、掌握度和复习日期
- 跨周或存在到期错题时，自动指出当前最优先的 3 个问题
- 每周自动复盘完成情况、薄弱点、到期错题和下周 4 小时安排

## 快速开始

在 Codex 中打开本项目后，可以直接提问，或显式调用：

```text
使用 $network-engineer-exam-prep 开始第 1 周诊断。
```

其他示例：

```text
使用 $network-engineer-exam-prep 解析这道题，并说明每个选项为什么对或错。
```

```text
使用 $network-engineer-exam-prep 考我 IPv4 子网划分，先不要告诉我答案。
```

```text
使用 $network-engineer-exam-prep 根据最近的错题调整本周计划，但总时间不要超过 4 小时。
```

发送题目截图时，请尽量保证题干、选项、拓扑图、接口名称和数值清晰。无法可靠识别的条件，助手会请你补充，不会猜题。

## 答疑方式

- 普通答疑：先给正确结论，再讲考点、推理、选项陷阱和记忆方法。
- 训练模式：只有当你明确说“先别给答案”或“考考我”时，才先给提示。
- 计算题：展示公式、单位、中间步骤和独立校验。
- 配置题：根据题干识别设备厂商；未指定时默认使用华为 VRP，并明确标注。
- Linux 操作：需要编辑配置文件时默认使用 `vim`。

## 8 周学习路径

| 周次 | 重点内容 |
|---|---|
| 第 1 周 | 诊断、数据通信、编码检错、IPv4 子网 |
| 第 2 周 | Ethernet、VLAN、STP、链路聚合、WLAN |
| 第 3 周 | TCP/IP、IPv6、静态与动态路由 |
| 第 4 周 | 华为配置、DHCP、NAT、ACL、网络服务 |
| 第 5 周 | 网络安全、Linux/国产操作系统、应用服务器 |
| 第 6 周 | 网络管理、故障排查、规划设计、专业英语和新增内容 |
| 第 7 周 | 240 分钟完整机考模拟 |
| 第 8 周 | 模考错题、薄弱点修复和考前速记 |

详细时间分配见 [周计划](study/weekly-plan.md)。每周任务上限为 240 分钟；新增高优先级任务时，应替换低收益任务，而不是不断叠加。

## 学习记录

助手只会自动修改 `study/` 目录：

```text
study/
├── profile.md              # 考试目标、个人画像和知识域掌握度
├── weekly-plan.md          # 八周计划、本周任务和实际投入
├── mistakes.md             # 错题、错误原因、掌握度和复习节点
├── review-state.md         # 入口检查、每周复盘和上次优先建议
└── sessions/
    └── YYYY-MM-DD.md       # 每日学习记录
```

首次错题默认安排在第 1、3、7、14 天复习。同一来源、题号和核心考点相同的错题会更新原记录，而不是重复添加。

## 周期复盘

- 每次新项目会话首次使用 Skill 时，会检查是否跨周、是否有到期错题、是否新增高风险错误，以及本周计划是否存在无法按时完成的风险。
- 触发时给出恰好 3 个优先问题，每项包含证据、调整原因、建议动作和预计时间；没有薄弱点证据时会推荐诊断任务，不会虚构问题。
- 每周日 20:30（Asia/Shanghai）自动读取学习档案、周计划、错题和最近 7 天会话，生成本周总结及下周不超过 240 分钟的安排。
- 复盘状态保存在 `study/review-state.md`，避免同一周反复提示相同建议。

## 考试口径

项目当前记录的考试信息核对于 2026-08-29：

- 2026 年下半年采用计算机化考试，考试窗口为 10 月 24—27 日，实际批次以准考证为准：[深圳市考试院](https://hrss.sz.gov.cn/szksy/zxxx/content/post_12939472.html)
- 基础知识与应用技术两科连考，总作答时间 240 分钟；基础知识最短 90 分钟、最长 120 分钟：[考试批次安排](https://rsj.sjz.gov.cn/columns/eeaf97d2-6159-4dc5-b730-c72e5861424c/202605/18/137eb7a1-926c-4079-9172-ba2cbb0b8f98.html)
- 两科满分均为 75 分，当前合格标准均为 45 分：[成绩与合格标准通告](https://www.changzhou.gov.cn/gi_news/287178287095094)
- 知识范围以依据 2024 年审定考纲编写的《网络工程师教程（第 6 版）》为主：[清华大学出版社](https://www.tup.tsinghua.edu.cn/booksCenter/book_10453401.html)

考试日期、报名和规则可能变化，询问这些信息时应重新核对当期官方通知。
